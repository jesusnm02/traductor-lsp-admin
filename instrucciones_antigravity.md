1. Control Absoluto de Dependencias en Windows
El mayor dolor de cabeza al desplegar MediaPipe, TensorFlow y Flet en Windows son las librerías nativas de red y las dependencias cruzadas. Le he ordenado a Antigravity aplicar tres filtros estrictos:
Prohibición de uvloop: Al ser una librería exclusiva de sistemas Unix, su compilación en Windows rompe el entorno virtual. He dado la orden de vetar esta instalación y forzar el uso de la política de event loop nativa de Windows (asyncio.WindowsSelectorEventLoopPolicy()).
Aislamiento y Mitigación de tensorflowjs: Dado que el compilador de TensorFlow.js suele exigir paquetes conflictivos de JAX/Flax en Windows, le he indicado instalar la suite de IA básica (TensorFlow + Keras) para asegurar el inicio de la app y manejar la conversión mediante el mecanismo programático secundario que dejamos listo en src/trainer.py, evitando bloqueos en la inicialización de la interfaz.
Gestión Estricta de Versiones: El archivo de instrucciones le proporciona un set exacto de dependencias probadas (como forzar numpy<2.0.0 para evitar colisiones binarias con TensorFlow y MediaPipe bajo Python 3.11).
2. Depuración Autónoma de la Interfaz (Flet API)
Las actualizaciones de Flet suelen introducir cambios en las llamadas de sus constructores (como el manejo de eventos on_change en los Dropdowns o las propiedades de tamaño de ventana page.window_width). He instruido a Antigravity para que ejecute la aplicación con el comando estándar flet run src/app.py y, ante cualquier fallo de ejecución (ModuleNotFoundError, TypeError o errores de sintaxis), lea el traceback, edite el código de forma quirúrgica en caliente, y vuelva a probar en un bucle autónomo hasta lograr que la ventana oscura de administración cargue limpia y funcional.
3. Cierre y Liberación de Recursos
El documento exige que, una vez que la GUI se levante con éxito, el agente verifique la desconexión asíncrona segura. Esto garantiza que OpenCV y el modelo Holistic de MediaPipe liberen la cámara web y la memoria RAM al cerrar el programa, previniendo cuellos de botella en la máquina del administrador.
